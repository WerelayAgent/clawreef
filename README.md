# Clawreef ($CLAWR) 🦀🌊

> **Autonomous AI Trading Critters on Solana**  
> Formulate trading strategies in plain English, approve modular cardlets, and execute with sub-second 1-slot precision.

---

## 🌟 Overview

**Clawreef** transforms unstructured human intuition into deterministic, risk-isolated execution plans on Solana. Powered by Claude Fable 5.2, Clawreef deploys five specialized autonomous critters to cover every phase of the mempool trading cycle:

- **Dig (The Hunter)**: Scrapes mempools to discover fresh dev clusters, insider seeders, and funded secondary wallets before bonding curves graduate.
- **Tide (The Copier)**: Mirrors tier-1 smart money alpha wallets with sub-second custom Jito bundle execution.
- **Pinch (The Sniper)**: Enters micro-cap bonding curves at block 0-1 on pump.fun with automated supply distribution checks.
- **Shell (The Guard)**: Enforces trailing stop-losses, trims exponential pumps, detects honeypot authorities, and cuts rugs instantly.
- **Scuttle (The Scout)**: Scans Telegram groups, Discord alpha channels, and social sentiment velocity to spot emerging narratives.

---

## ⚡ The 3-Step Loop: Say it. Approve it. Watch it.

1. **Say it**: Speak or type in plain natural language (e.g. *"Dig, track dev wallets funded 10m before deploy and snipe 0.5 SOL with Pinch"*).
2. **Approve it**: The engine compiles your intent into an isolated **Cardlet** blueprint containing exact slippage caps, stop-loss triggers, and Jito tip parameters.
3. **Watch it**: Critters execute in the targeted Solana slot and deliver transparent cryptographic receipts with millisecond latency metrics.

## 🖥️ Scope CLI Terminal

Clawreef features an embedded interactive web terminal:
- `help`: Lists all supported terminal commands
- `status`: Checks RPC health, active slot, and critter states
- `critters`: Displays live telemetry across the squad
- `dossier`: Reviews recent insider catches discovered by Dig
- `burn`: Displays upcoming buyback & burn countdown and accumulated pot
- `balance`: Checks connected Solana wallet balance and fee tier

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/WerelayAgent/clawreef.git

# Navigate into project directory
cd clawreef

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
